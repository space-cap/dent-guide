# 구현 계획

## 1. 목표

최소한의 코드로 빠르게 검증 가능한 **치과 가격 Q&A MVP**를 완성한다.

우선순위는 아래와 같다.

1. 가격 데이터를 안전하게 관리할 수 있어야 한다.
2. 질문하면 관련 가격을 찾아 답변할 수 있어야 한다.
3. 애매한 질문도 일정 수준 처리할 수 있어야 한다.
4. Vercel에 배포 가능해야 한다.

권장 개수:

## 5. 테스트 질문 예시

### direct 매칭
- "레진 얼마야?"
- "지르코니아 크라운 가격 알려줘"
- "임플란트 비용은?"

### alias 매칭
- "흰색 크라운 얼마야?"
- "하얀 크라운 비용"
- "골이식 가격"

### ambiguous 매칭
- "크라운 얼마야?"
- "보철 비용 궁금해"

### not_found
- "사랑니 수면마취 비용 얼마야?"
- 데이터에 없는 항목 질문

## 6. 완료 정의

MVP 1차는 아래가 되면 완료로 본다.

- JSON 파일 하나로 가격 데이터를 관리할 수 있다.
- 사용자가 웹 UI에서 질문을 입력할 수 있다.
- API가 가격 데이터를 찾아 응답한다.
- 공개 정책에 따라 exact / range / inquiry_only를 구분한다.
- 찾지 못하면 추측하지 않고 안전하게 응답한다.
- Vercel에서 배포 후 실제로 동작한다.
